## Featured Projects

### [Image Quality & Corruption Detection](https://github.com/snehasunill/image-quality-corruption-detection)

Built an image corruption detection pipeline using OpenCV, scikit-learn, and PyTorch. Compared Random Forest, a custom CNN, and ResNet18 on synthetic image-quality defects, and deployed a Dockerized FastAPI inference service.

**Tech:** Python · PyTorch · OpenCV · scikit-learn · FastAPI · Docker

### [ML Performance Analytics Dashboard](https://github.com/snehasunill/ml-performance-analytics-dashboard)

Developed a benchmarking pipeline to compare image-classification models across input resolutions, using SQLite and SQL to analyze accuracy, inference latency, and throughput across 45 experimental runs.

Built an interactive Tableau dashboard with adjustable performance thresholds and dynamic model rankings.

**Tech:** Python · SQL · SQLite · pandas · Tableau
